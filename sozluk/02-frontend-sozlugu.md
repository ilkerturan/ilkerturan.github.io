# Teknik Sözlük 2: Frontend (Arayüz ve Kullanıcı Deneyimi)

Web tarayıcısında (Google Chrome vb.) gördüğümüz, tıkladığımız ve etkileşime girdiğimiz ön yüz dünyasına ait terimler.

---

*   **DOM (Document Object Model):** HTML kodlarınızın tarayıcı tarafından okunduktan sonra oluşturduğu "Ağaç (Tree)" yapısı. JavaScript bu ağacın dallarındaki yaprakları (butonları) bulup rengini değiştirebilir.
*   **Element & Tag (Etiket):** `<button>Tıkla</button>` yapısındaki `<button>` bir Tag (Etiket)'tir. İkisinin birleştiği bütüne ise Element denir.
*   **Responsive (Duyarlı Tasarım):** Bir web sitesinin telefonda, tablette ve devasa bir televizyonda aynı anda düzgün, bozulmadan (esneyerek) görünmesi.
*   **Flexbox & Grid:** Elementleri ekranda yan yana, alt alta, hizalı ve boşluklu bir şekilde "Kutu gibi" yerleştirmemizi sağlayan modern CSS teknolojileri.
*   **Async (Asenkron):** Bir işlemin bitmesini beklemeden diğer işleme geçebilme yeteneği. (Garsonun siparişi mutfağa verdikten sonra beklemeyip diğer masaya gitmesi).
*   **Promise:** "Söz vermek". Bir verinin (Örn: İnternetten hava durumu) şu an elimde olmadığı, ama 2 saniye sonra başarılı veya başarısız olarak döneceğine dair verilen söz.
*   **Callback:** Bir işlem bittikten HAKMEN sonra çalışması için gönderilen "Geri Çağırma" fonksiyonu.
*   **API (Application Programming Interface):** Garson. Müşteri (Frontend) ile Mutfak (Backend/Veritabanı) arasındaki veriyi taşıyan ve anlaşmalarını sağlayan köprü/menü.
*   **Fetch (Getirmek):** JavaScript'in, arka plandaki bir API'ye (Sunucuya) gidip veri (Örn: Kullanıcı listesi) getirmesini sağlayan komut.
*   **JSON (JavaScript Object Notation):** İnternet dünyasındaki evrensel veri taşıma formatı. Sistemler (Örn: Java ile Python) birbiriyle JSON (`{"isim":"Ali"}`) dilini kullanarak mesajlaşır.
